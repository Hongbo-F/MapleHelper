Everything here is a Python program started as `python -m gamelab <command>` (or `maplehelper`, `gamedata`). While the bot plays, four of them run side by side, each its own Windows process:

- **The perception service** (`perceive`) is the bot's only eye. It captures the game 15 times a second and hands what it saw to every other program over one named pipe, `\\.\pipe\gamelab-perceive`. Only one runs per PC.
- **A hunting command** (`tour --loop`, `hunt`, `nav`, ...) is the brain. It reads the service's picture of the game, decides what to do, and writes every key it wants pressed as a JSON plan into `gamelab/lab/inbox/`. It never captures the screen and never presses a key itself (it does bring the game's window to the front when it needs to).
- **The key player** (`player --elevate`) is the only hand. MapleStory runs as administrator, and Windows doesn't let normal programs send keys to administrator windows. So this one small program runs elevated: it plays the plans from the inbox with SendInput and answers in `lab/outbox/`. It also watches the screen 4 times a second for the Lie Detector on its own, and stops every key the moment it sees one. Only one runs per PC.
- **The pet feeder** (`pet --every 1`) runs between hunts instead of a hunting command. It keeps her pet fed, and its guard parks her somewhere safe if she's being hit while nobody hunts.

**Who starts them.** You start the key player by hand (one UAC click), and you or Claude start the hunting commands. Everything else starts on its own. The **babysitter**, a PowerShell loop outside this repo (`D:/MapleHelper-scratch/live/babysit3.ps1`, started once per sitting), checks every 5 seconds and starts the perception service and the pet feeder when they're missing. It stops the pet feeder while a hunt runs. Any command that needs the service and finds none starts it too. The service starts two helper processes of its own when needed: a Lie Detector mini-game tracker and a recording writer.

**Watching it.** The mini-map (`minimap`, or `web` for a phone) follows the programs' telemetry files and serves the live map at maple.eirage.com through the Cloudflare tunnel. It never touches the game.
